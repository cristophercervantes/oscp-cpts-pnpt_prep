# Navigation
## 1. Why the Terminal?

- **Speed**: Much faster than navigating via GUI.
    
- **Control**: Precision over system actions.
    
- **Tooling**: Essential cybersecurity tools are often CLI-only.
    

## 2. Core Navigation Commands

|**Command**|**Action**|**Meaning**|
|---|---|---|
|`pwd`|**Print Working Directory**|"Where am I?" Displays the full path of your current folder.|
|`ls`|**List Content**|"What's around me?" Shows files and folders.|
|`ls -l`|**Long List**|Shows extra details: permissions, file size, and timestamps.|
|`ls -al`|**List All**|Includes **hidden files** (files starting with a dot `.`).|
|`cd <dir>`|**Change Directory**|Moves you into a specific folder.|
|`cd ..`|**Go Back**|Moves you up one level in the folder hierarchy.|

## 3. Finding & Reading Files

### **Finding a File**

If you know a filename but not its location, use the `find` utility:

`find <starting_point> -name <filename>`

- **Example**: `find ~ -name mission_brief.txt`
    
- **Note**: The tilde `~` represents your **Home Directory**.
    

### **Reading a File**

To view the text inside a file without opening an editor:

`cat <filename>`

# Investigating the System
## 1. User & Identity

Knowing who you are on a system is critical for understanding your permissions.

- `whoami`: Displays the username of the current session.
    

## 2. System Hardware & Kernel Details

- `uname`: Displays the operating system name (Linux).
    
- `uname -a`: Provides a full "All" report including:
    
    - **Kernel Version**: Essential for identifying vulnerabilities.
        
    - **Hostname**: The name assigned to the machine.
        
    - **Architecture**: (e.g., `x86_64`) tells you if the system is 64-bit.
        

## 3. Storage & Disk Usage

- `df -h`: Displays **Disk Free** space.
    
    - The `-h` flag is crucial; it stands for **Human Readable** (converts bytes into GB/MB).
        
    - **Note**: Filesystems like `tmpfs` are stored in **RAM**, not on the physical hard drive.
        

## 4. Identifying the Distribution

While `uname` gives kernel info, identifying the specific "flavor" of Linux (Ubuntu, Debian, CentOS) is done via system files in the `/etc` directory.

- `cat /etc/os-release`: The standard file for identifying the OS name and version.
