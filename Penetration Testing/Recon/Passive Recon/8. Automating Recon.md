# Automating Recon

Manual recon works, but it's slow and you'll make mistakes. Automating it saves time, scales better, and gives you consistent results every time.

## Why Bother Automating?

- **Speed** — tools blast through repetitive tasks way faster than doing it by hand
- **Scale** — you can run recon across many targets at once
- **Consistency** — no human error, same process every time
- **Coverage** — DNS enum, subdomain discovery, crawling, port scanning — all in one go
- **Integration** — most frameworks plug into other tools, so your workflow stays clean

## Common Recon Frameworks

|Tool|What it does|
|---|---|
|**FinalRecon**|Modular Python tool — headers, Whois, SSL, crawling, DNS, subdomains, directories|
|**Recon-ng**|Powerful modular framework — DNS, subdomains, ports, crawling, even some exploits|
|**theHarvester**|Pulls emails, subdomains, hosts, open ports from public sources (search engines, Shodan, etc.)|
|**SpiderFoot**|OSINT automation — IPs, domains, emails, social profiles, integrates many data sources|
|**OSINT Framework**|A collection/index of OSINT tools covering social media, public records, search engines, and more|

## FinalRecon 

This one's worth knowing well. It covers a lot of ground.

**What it can grab:**

- **Headers** — server info, tech stack, potential misconfigs
- **Whois** — registrant info, creation/expiry dates, registrar
- **SSL cert** — validity, issuer, details
- **Crawl** — links (internal/external), images, `robots.txt`, `sitemap.xml`, JS links, Wayback Machine data
- **DNS** — queries 40+ record types including DMARC
- **Subdomains** — pulls from crt.sh, AnubisDB, ThreatMiner, CertSpotter, VirusTotal, Shodan, etc.
- **Directories** — custom wordlist + file extension support
- **Wayback** — last 5 years of URLs from the Wayback Machine

## Installing FinalRecon

```bash
git clone https://github.com/thewhiteh4t/FinalRecon.git
cd FinalRecon
pip3 install -r requirements.txt
chmod +x ./finalrecon.py
./finalrecon.py --help
```

##  Flags

|Flag|What it does|
|---|---|
|`--url URL`|Target URL|
|`--headers`|Grab header info|
|`--sslinfo`|SSL cert details|
|`--whois`|Whois lookup|
|`--crawl`|Crawl the site|
|`--dns`|DNS enumeration|
|`--sub`|Subdomain enum|
|`--dir`|Directory search|
|`--wayback`|Wayback URLs|
|`--ps`|Fast port scan|
|`--full`|Run everything|

**Extra options:**

|Flag|What it does|
|---|---|
|`-w W`|Custom wordlist path|
|`-e E`|File extensions (e.g. `txt,php,xml`)|
|`-T T`|Request timeout (default 30s)|
|`-d D`|Custom DNS server (default `1.1.1.1`)|
|`-o O`|Export format (default `txt`)|
|`-k K`|Add API key (e.g. `shodan@yourkey`)|

## Example Usage

Run headers + Whois on a target:

```bash
./finalrecon.py --headers --whois --url http://inlanefreight.com
```

Sample output gives you things like:

- Server: `Apache/2.4.41 (Ubuntu)`
- IP: `134.209.24.248`
- Domain registrar, creation date, expiry, name servers, DNSSEC status

Results also get exported automatically to `~/.local/share/finalrecon/dumps/`.


Start with `--headers` and `--whois` to get a fast overview, then go deeper with `--dns`, `--sub`, or `--full` depending on the scope of your engagement.
