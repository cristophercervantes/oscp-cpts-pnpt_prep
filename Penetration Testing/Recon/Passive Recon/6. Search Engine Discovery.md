# Search Engine Discovery / Google Dorking

Search engines index a huge chunk of the internet, including stuff that was never meant to be public. Google dorking is just using search operators to find that stuff.

## Essential operators

|Operator|What it does|Example|
|---|---|---|
|`site:`|Limit to a specific domain|`site:example.com`|
|`inurl:`|Term must be in the URL|`inurl:login`|
|`intitle:`|Term must be in the page title|`intitle:"admin panel"`|
|`intext:`|Term must be in the page body|`intext:"password reset"`|
|`filetype:`|Specific file type only|`filetype:pdf`|
|`cache:`|Google's cached version of the page|`cache:example.com`|
|`" "`|Exact phrase match|`"confidential report"`|
|`-`|Exclude a term|`site:example.com -inurl:login`|
|`*`|Wildcard|`user* manual`|
|`OR` / `AND` / `NOT`|Logic operators|`inurl:admin OR inurl:login`|
|`..`|Number range|`"price" 100..500`|

## Google dorks worth knowing

**Login pages:**

```
site:example.com inurl:login
site:example.com (inurl:login OR inurl:admin)
```

**Exposed files:**

```
site:example.com filetype:pdf
site:example.com (filetype:xls OR filetype:docx)
```

**Config files:**

```
site:example.com inurl:config.php
site:example.com (ext:conf OR ext:cnf)
```

**Database backups:**

```
site:example.com inurl:backup
site:example.com filetype:sql
```
