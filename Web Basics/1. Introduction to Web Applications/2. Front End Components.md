# HTML - HyperText Markup Language

## What is HTML?

**HTML** (HyperText Markup Language) is the **foundation** of every web page. It defines the **structure** and **content** of what users see in their browser.

- The browser reads HTML and renders it into a visual page.
- It works together with **CSS** (styling) and **JavaScript** (interactivity).

### Basic HTML Example
```
<!DOCTYPE html>
<html>
    <head>
        <title>Page Title</title>
    </head>
    <body>
        <h1>A Heading</h1>
        <p>A Paragraph</p>
    </body>
</html>
```

This produces:

- A page title in the browser tab
- A large heading
- A normal paragraph

## HTML Document Structure (DOM Tree)

HTML is organized like a **tree** (similar to XML):
```
document
 └─ html
     ├─ head
     │   └─ title
     └─ body
         ├─ h1
         └─ p
```

### Key Rules:

- Every element has an **opening tag** <tag> and a **closing tag** </tag>
- Content goes **between** the tags
- Tags can have **attributes**:
    - id → unique identifier (e.g., `<p id="para1">`)
    - class → for grouping elements (used heavily by CSS)

**Example with attributes**:
```
<p id="welcome" class="red-text">This is a paragraph</p>
```
## Important HTML Sections

Understanding page structure is the first step in identifying application logic and potential injection points.

| Section | Purpose | Contains |
| :--- | :--- | :--- |
| `<head>` | Metadata (not visible on the page) | Title, meta tags, links to CSS, scripts, etc. |
| `<body>` | All visible content | Headings, paragraphs, forms, images, UI elements |
| `<style>` | CSS rules (can be inside head or body) | Styling code |
| `<script>` | JavaScript code | Interactivity and client-side logic |

## URL Encoding (Percent-Encoding)

Browsers and servers communicate using ASCII in URLs. Any special characters outside this standard range, or characters with reserved structural meanings in a URL, must be encoded.

> [!abstract] Common Encodings Quick Reference
> | Character | Encoded | Character | Encoded |
> | :--- | :--- | :--- | :--- |
> | **Space** | `%20` or `+` | **!** | `%21` |
> | **'** (Single quote) | `%27` | **"** (Double quote) | `%22` |
> | **&** (Ampersand) | `%26` | **#** | `%23` |
> | **$** | `%24` | **%** | `%25` |
> | **(** | `%28` | **)** | `%29` |

> [!danger] Pentester Perspective
> Many web vulnerabilities (such as XSS, SQLi, and Command Injection) rely heavily on injecting special characters to break out of expected data formats.
> * You will frequently need to encode payloads to bypass input validation/WAFs, or decode server responses to analyze data flow.
> * **Standard Tooling:** Burp Suite Decoder, CyberChef.
## DOM (Document Object Model)

The DOM is the browser's method of representing the loaded HTML page as a programmable, hierarchical object tree.

**W3C Definition:**
*"A platform and language-neutral interface that allows programs and scripts to dynamically access and update the content, structure, and style of a document."*

### DOM Categories
* **Core DOM:** General model for any document.
* **XML DOM:** Designed for XML documents.
* **HTML DOM:** Specifically mapped for HTML pages.

### Accessing Elements (JavaScript)
You can interact with the DOM dynamically to manipulate the page state:

```javascript
// Accessing high-level document structures
let pageHead = document.head;
let pageBody = document.body;

// Targeting a specific element by its ID attribute
let welcomeElement = document.getElementById("welcome");
```

# CSS
## What is CSS?

CSS stands for **Cascading Style Sheets**. It’s the language we use to tell the browser how HTML elements should look.

- **Version Evolution:** Just like phone apps, CSS gets updates. New versions bring new "tricks" (like 3D effects), and browsers update their software to make sure they can render those tricks correctly.
    
- **The "Global" Rule:** CSS lets you set a rule once (e.g., "all headers should be blue") and it applies to every header on the page.
    
## The Syntax (How to write it)

Writing CSS is like giving a specific instruction. It follows a simple pattern:

`Selector { Property : Value; }`

### Breakdown of the Code:

Using your example:
```
body { 
  background-color: black; 
}

h1 { 
  color: white; 
  text-align: center; 
}
```

- **Selector (`h1`):** Who are you talking to? (In this case, all Level 1 Headings).
    
- **Property (`color`):** What do you want to change? (The text color).
    
- **Value (`white`):** What change are you making? (Turn it white).
    
##  The Box Model & Layout

Everything in CSS is essentially a box. To design a page, you manipulate these boxes using:

- **Dimensions:** `height`, `width`.
    
- **Spacing:** `margin` (space _outside_ the box) and `padding` (space _inside_ the box).
    
- **Decoration:** `border`, `color`, `font-size`.
    

## Advanced Magic: Animations & Depth

CSS isn't just static; it can move!

- **Animations:** Using `@keyframes`, you can make elements slide, fade, or bounce.
    
- **Parallax & 3D:** When combined with **JavaScript**, CSS can create "depth" effects (like the Andy Merskin example), where layers move at different speeds to look 3D.
    
- **Interactivity:** It can react to your mouse cursor or keyboard inputs to change styles on the fly.
    
##  CSS Frameworks 

Writing every single line of CSS from scratch can be exhausting and repetitive. To save time, developers use **Frameworks**—pre-written libraries of CSS that give you "ready-made" components like buttons, navbars, and grids.

|**Framework**|**Vibe/Benefit**|
|---|---|
|**Bootstrap**|The most popular; great for "mobile-first" responsive sites.|
|**SASS**|Actually a "pre-processor" that makes CSS more powerful (using variables/logic).|
|**Bulma**|Modern and based on Flexbox (very easy to learn).|
|**Foundation**|Highly professional and flexible for complex sites.|
|**Pure**|Super tiny and lightweight; only the essentials.|


# Javascript
## What is JavaScript?

JavaScript is the engine of the modern web. While it started as a simple tool to make things blink or pop up, it has evolved into a powerhouse language.

- **Front End:** Runs in your browser (Chrome, Safari) to make buttons click, forms validate, and maps move.
    
- **Back End:** Using **Node.js**, JavaScript can now run on servers, talk to databases, and handle the "brain" of an entire application.
    
- **The "Action" Language:** Without JS, a website is just a digital poster. With JS, it’s an interactive app (like Facebook or Gmail).
    
## How It’s Added to a Page

You don't just write JS anywhere; you have to tell the browser where the "logic" begins using the `<script>` tag.

1. **Internal:** Writing code directly inside the HTML file.
    ```
    <script> alert("Hello World!"); </script>
    ```
    
2. **External:** Linking to a separate file (the professional way).
    ```
    <script src="myscripts.js"></script>
    ```
## Core Capabilities

JavaScript does the "heavy lifting" that HTML and CSS can't touch:

- **DOM Manipulation:** This is fancy talk for "changing the page after it has loaded." For example, clicking a button to change text from "Login" to "Welcome!"
    
- **Event Handling:** JS listens for what the user does (clicks, scrolls, keypresses) and triggers a reaction.
    
- **Data Fetching (AJAX):** JS can "talk" to a server to get new data (like new emails or sports scores) without refreshing the entire page.
    
## Frameworks: Building Faster

As websites got more complex, writing "Vanilla" (pure) JavaScript became slow and messy. Frameworks provide a pre-built structure so developers don't have to reinvent the wheel.

|**Framework**|**What it’s known for**|
|---|---|
|**React**|Created by Meta; uses "components" to build fast, reusable UI pieces.|
|**Angular**|Created by Google; a heavy-duty framework for massive, complex apps.|
|**Vue**|Known for being lightweight and very easy for beginners to pick up.|
|**jQuery**|An older "classic" that simplified how we select HTML elements.|
