### **Python Modules for DNS Zone Transfer Tool 

Before writing code, we need to choose the right Python modules and understand how to use them for DNS zone transfers.

#### **Main Modules We Need**

1. **dnspython** – The core library for DNS operations in Python
2. **IPython** – Optional but very helpful during development (better auto-completion and interactive help)

Install dnspython:
```
pip3 install dnspython
```

#### **Classes & Functions from dnspython**

- **dns.zone** → Handles zone files and zone transfers
    - from_xfr() → Converts the result of a zone transfer into a usable Zone object
- **dns.query** → Performs low-level DNS queries
    - xfr() → Performs the actual zone transfer (AXFR)
- **dns.resolver** → High-level DNS resolver
    - Allows us to query specific DNS servers and retrieve records (like NS records)
- **argparse** → For handling command-line arguments (makes the tool user-friendly)

#### **Understanding the Core Functions**

**1. dns.zone.from_xfr()**

This function takes the output of a zone transfer and turns it into a Zone object we can work with.

From the help:
```
from_xfr(xfr, zone_factory=..., relativize=True, check_origin=True)
```

**2. dns.query.xfr()**

This actually performs the zone transfer.

Required parameters (no defaults):

- where → The DNS server (IP or hostname) to request the transfer from
- zone → The domain name (zone) we want to transfer

Example skeleton:
```
axfr = dz.from_xfr(dq.xfr(nameserver, domain))
```

#### **Finding Name Servers First**

Before attempting a zone transfer, we need the authoritative name servers for the domain.

Using dns.resolver:
```
import dns.resolver as dr

NS = dr.Resolver()
nameservers = NS.query('inlanefreight.com', 'NS')

for ns in nameservers:
    print('NS:', ns)
```

This gives us something like:

- ns1.inlanefreight.com
- ns2.inlanefreight.com

We then set these as our resolver’s nameservers:
```
NS.nameservers = ['ns1.inlanefreight.com', 'ns2.inlanefreight.com']
```

### **Building the AXFR Function

When writing tools, it’s good practice to break complex processes into **separate functions**. This makes the code easier to read, debug, and extend later — especially once the script grows beyond a few hundred lines.

For our DNS Zone Transfer tool, we create one dedicated function called AXFR() that handles the entire zone transfer process for a given domain and nameserver.

#### **Function Design Principles**

- Keep the number of arguments low (ideally ≤ 3) to reduce errors.
- Use clear function names (we’re using capital letters for functions here).
- Add comments to explain each major step inside the function.

#### **Structure of the AXFR Function**
```
# List to store discovered subdomains
Subdomains = []

def AXFR(domain, nameserver):
    """Attempts a DNS zone transfer for the given domain and nameserver."""

    try:
        # Perform the actual zone transfer
        axfr = dz.from_xfr(dq.xfr(nameserver, domain))

        # If the transfer was successful
        if axfr:
            print(f'[*] Successful Zone Transfer from {nameserver}')

            # Extract and store subdomains
            for record in axfr:
                Subdomains.append(f'{record.to_text()}.{domain}')

    except Exception as error:
        # Gracefully handle any errors (e.g. transfer refused, timeout, etc.)
        print(error)
        pass
```

#### Parts Explained

1. **Try-Except Block**
    - We wrap the zone transfer in a try block because many things can go wrong (refused transfer, connection timeout, no SOA record, etc.).
    - The except block catches any exception, prints a message, and continues gracefully instead of crashing the tool.
2. **If-Else Logic**
    - After a successful transfer (axfr is not empty), we print a success message.
    - Then we loop through the records and extract subdomains.
3. **For Loop**
    - Iterates over every record returned in the zone transfer.
    - Appends each subdomain in the format subdomain.domain.com to our global Subdomains list.

### **Main Function

Our goal for the main block:

- Call the AXFR() function for each one
- After all attempts, show the results (list of discovered subdomains)


This is clean and scalable — if we later add more nameservers, the loop handles them automatically.

#### **Printing the Results**

After trying zone transfers on all nameservers, we check if we found any subdomains:

**Why if Subdomains: works**: In Python, an empty list is "falsy", so this is a clean way to check if we actually found anything.

#### **Complete DNS-AXFR.py Script**

Here’s the full script we’ve built so far:
```
#!/usr/bin/env python3

# Dependencies:
# python3-dnspython

import dns.zone as dz
import dns.query as dq
import dns.resolver as dr
import argparse

# Initialize Resolver
NS = dr.Resolver()

# Target domain
Domain = 'inlanefreight.com'

# Set the authoritative nameservers
NS.nameservers = ['ns1.inlanefreight.com', 'ns2.inlanefreight.com']

# List to store discovered subdomains
Subdomains = []

def AXFR(domain, nameserver):
    """Attempts a DNS zone transfer for the given domain and nameserver."""
    try:
        # Perform the zone transfer
        axfr = dz.from_xfr(dq.xfr(nameserver, domain))

        # If zone transfer was successful
        if axfr:
            print(f'[*] Successful Zone Transfer from {nameserver}')

            # Add found subdomains to global list
            for record in axfr:
                Subdomains.append(f'{record.to_text()}.{domain}')

    except Exception as error:
        print(error)
        pass

# Main
if __name__ == "__main__":
    # Try AXFR for each nameserver
    for nameserver in NS.nameservers:
        AXFR(Domain, nameserver)

    # Print the results
    if Subdomains:
        print('-------- Found Subdomains:')
        for subdomain in Subdomains:
            print(subdomain)
    else:
        print('No subdomains found.')
        exit()
```

**DNS-AXFR.py - Final Version with Argparse**

Now that the core AXFR function works, we make the script **professional and user-friendly** by adding command-line argument support using Python’s built-in argparse module. This lets us run the tool flexibly without editing the code every time.

### **Why Add Argparse?**

- No more hard-coded domain and nameservers
- Easy to use from the terminal (-d, -n, -v, -h)
- Professional help text and error messages
- Easy to extend later with more options

### **Setting Up the Argument Parser**

In the if __name__ == "__main__": block, we create the parser and define the options:
```
if __name__ == "__main__":
```

### **Complete Final Script (dns-axfr.py)**
```
#!/usr/bin/env python3

# Dependencies:
# python3-dnspython

import dns.zone as dz
import dns.query as dq
import dns.resolver as dr
import argparse

# Initialize Resolver
NS = dr.Resolver()

# List of found subdomains
Subdomains = []

def AXFR(domain, nameserver):
    """Attempts a DNS zone transfer for the given domain and nameserver."""
    try:
        axfr = dz.from_xfr(dq.xfr(nameserver, domain))

        if axfr:
            print(f'[*] Successful Zone Transfer from {nameserver}')
            for record in axfr:
                Subdomains.append(f'{record.to_text()}.{domain}')

    except Exception as error:
        print(error)
        pass

# Main
if __name__ == "__main__":
    # ArgParser - Define usage
    parser = argparse.ArgumentParser(
        prog="dns-axfr.py",
        epilog="DNS Zonetransfer Script",
        usage="dns-axfr.py [options] -d <DOMAIN>",
        prefix_chars='-',
        add_help=True
    )

    # Positional Arguments
    parser.add_argument('-d', action='store', metavar='Domain', type=str,
                        help='Target Domain. Example: inlanefreight.htb', required=True)
    parser.add_argument('-n', action='store', metavar='Nameserver', type=str,
                        help='Nameservers separated by a comma. Example: ns1.inlanefreight.htb,ns2.inlanefreight.htb')
    parser.add_argument('-v', action='version', version='DNS-AXFR - v1.0',
                        help='Prints the version of DNS-AXFR.py')

    # Assign given arguments
    args = parser.parse_args()

    # Check required arguments
    if not args.d:
        print('[!] You must specify target Domain.\n')
        print(parser.print_help())
        exit()

    if not args.n:
        print('[!] You must specify target nameservers.\n')
        print(parser.print_help())
        exit()

    # Variables
    Domain = args.d
    NS.nameservers = list(args.n.split(","))

    # Try AXFR for each nameserver
    for nameserver in NS.nameservers:
        AXFR(Domain, nameserver)

    # Print the results
    if Subdomains:
        print('-------- Found Subdomains:')
        for subdomain in Subdomains:
            print(subdomain)
    else:
        print('No subdomains found.')
        exit()
```
