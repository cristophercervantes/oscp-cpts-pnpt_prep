### ***DNS Enumeration***

DNS is a goldmine of information during penetration tests. It can reveal subdomains, hosts, IP addresses, mail servers, and even internal network structure if misconfigured.

We usually break DNS enumeration into three main categories:

- DNS Records
- Subdomains / Hosts
- DNS Security (especially zone transfer vulnerabilities)

#### **Main Techniques for DNS Enumeration**

1. **OSINT (Open-Source Intelligence)**
2. **Certificate Transparency Logs**
3. **Zone Transfers**

#### **1. OSINT for DNS**

Use public search engines and tools to gather known DNS information without directly querying the target.

Useful resources:

- Google / Bing with Google Dorks
- **VirusTotal** – Shows known subdomains and resolutions
- **DNSdumpster** – Visual DNS reconnaissance tool
- **Netcraft** – Historical DNS and hosting data

These tools often reveal subdomains and hosts that are already indexed publicly.

#### **2. Certificate Transparency (CT) Logs**

SSL/TLS certificates must be logged publicly for transparency. These logs are a fantastic source for discovering subdomains.

**Tool: ctfr.py**
```
python3 ctfr.py -d inlanefreight.com
```

This tool pulls subdomain names from various CT log sources. In the example, it revealed subdomains like:

- vc.inlanefreight.com
- wlan.inlanefreight.com
- autodiscover.inlanefreight.com
- kfdcex07.inlanefreight.com
- etc.

**Why it works**: Certificates often include all subdomains the owner wanted to secure.

#### **3. DNS Zone Transfer (AXFR)**

This is one of the most powerful (and dangerous) enumeration techniques.

**What is a Zone Transfer?**

- It allows a secondary DNS server to get a full copy of the zone file from the primary server.
- If the server is misconfigured and allows **anyone** to request a zone transfer, we can download the entire DNS database.

**How to test for it:**
```
dig axfr inlanefreight.com @10.129.2.67
```

If successful, you will receive:

- All A records (IP addresses)
- All subdomains
- NS records
- MX records
- SOA record
- And much more

**It shows**:

- Reveals the full internal naming structure
- Exposes hosts that were never meant to be public
- Greatly expands your attack surface
