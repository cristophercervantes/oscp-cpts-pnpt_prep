### **Command Prompt Basics (CMD.exe) 

The **Command Prompt** (also called **cmd.exe** or **CMD**) is the original command-line interpreter for Windows. It has been around since the DOS days and is still present on every Windows machine.

Even though PowerShell is more powerful, knowing CMD is essential — especially in restricted environments where PowerShell might be blocked by AppLocker or other controls.

- Many modern Windows hosts still have legacy components.
- In some cases, PowerShell is heavily restricted, but CMD remains available.
- CMD is lighter on resources and useful for quick tasks.
- It allows "living off the land" — using built-in tools without uploading anything new.

During assessments, pentesters have bypassed PowerShell restrictions by using CMD to escalate privileges and continue the attack.

#### **Local Access vs Remote Access**

**Local Access**

- You have direct/physical (or VM) access to the machine.
- No network required.
- Open CMD by:
    - Press Windows + R → type cmd → Enter, or
    - Navigate to C:\Windows\System32\cmd.exe

**Remote Access**

- Access the machine over the network using virtual peripherals.
- Common methods: SSH, PsExec, WinRM, RDP, Telnet (not recommended).
- Very convenient for admins, but also a big security risk if not properly secured (weak credentials, misconfigurations, etc.).

#### **Basic Usage of CMD**

The Command Prompt works like a simple conversation:

- You type a command
- The system responds with output

**Example – Using dir command:**
```
C:\Users\user\Desktop> dir
```

**Output shows:**

- Current directory path
- List of files and folders
- File sizes and dates
- Free space on the drive

**Navigation Basics**:

- Think of directories as hallways with doors (files and subfolders).
- Use dir to see what’s inside the current hallway.

#### **Case Study: Windows Recovery / Sticky Keys Attack**

This is a classic privilege escalation technique using CMD:

1. Boot from Windows installation media → Repair Mode → Command Prompt.
2. Replace sethc.exe (Sticky Keys) with a copy of cmd.exe.
3. Reboot normally.
4. At the login screen, press **Shift** five times → instead of Sticky Keys, you get a **CMD prompt running as SYSTEM** (highest privileges).

This bypasses normal login authentication and gives full control of the machine.

Physical access + recovery tools can be very dangerous.

### **Getting Help in Command Prompt (CMD.exe) **

When you first open CMD and see a blank prompt, it can feel overwhelming. The good news is that CMD has a built-in **help system** that works even without internet access.

#### **How to Use the Help System**

1. **List all built-in commands**:
    ```
    help
    ```
    
    This shows a list of available commands with short descriptions.
    
1. **Get detailed help for a specific command**:
    ```
    help <command>
    # Example:
    help time
    ```
    
    This displays full usage instructions, switches, and examples.
    

**Important Note**: Not every command works with help. Some external commands (like ipconfig) will tell you to use /? instead.

**Alternative way (works for most commands)**:
```
<command> /?
# Example:
ipconfig /?
```

#### **Why the Help System is Important**

In real penetration tests or restricted environments, you may:

- Have no internet access
- Be blocked from external sites
- Be working on air-gapped systems

The built-in help acts like an **offline manual** (similar to man pages on Linux). It allows you to quickly recall syntax and options when you need them most.

**Real-world scenario**: You’re dropped into a CMD session during an internal assessment with no outbound internet. You need to remember the exact syntax for a command. The help utility becomes your best friend.

#### **Additional Help Resources (When You Have Internet)**

- **Microsoft Official Documentation** – Complete reference for all CMD commands
- **ss64.com** – Excellent quick reference for CMD, PowerShell, Bash, and more

Use these when you have connectivity, but always practice using the offline help and /? first.

#### **Basic Tips & Tricks**

**1. Clear the Screen**
```
cls
```

- Clears all previous output so you can start fresh.
- Very useful when the screen gets cluttered with too many results.

**2. Command History** CMD keeps track of commands you’ve typed in the current session.

**Ways to access history:**

- Use **Up Arrow** (↑) and **Down Arrow** (↓) to scroll through previous commands
- doskey /history → Shows the full list of commands run in the current session

**Note**: History is **not persistent**. Once you close the CMD window, it’s gone.

**Useful History Shortcuts:**

|Key / Command|Description|
|---|---|
|↑ / ↓|Scroll through history|
|doskey /history|Show full command history|
|F7|Opens interactive list of previous commands|
|F9|Run a command by its history number|
|Page Up|Jump to first command|
|Page Down|Jump to last command|

**3. Interrupt a Running Command** Press **Ctrl + C** to stop a currently running process (e.g., a long ping).

Example:
```
ping 8.8.8.8
# Press Ctrl + C to stop it
^C
```

This is useful when a command is taking too long or you already have the information you need.

### **System Navigation in Command Prompt 

Now that we understand the basics of CMD, it’s time to learn how to **move around** the Windows file system efficiently.

#### **1. Listing a Directory (dir)**

The dir command is one of the most used commands in CMD. It shows the contents of the current directory.

**Basic usage:**
```
dir
```

**What the output shows:**

- Current directory path
- List of files and subfolders
- File sizes and modification dates
- Number of files and free disk space

**Tip**: Use dir /? to see all available options (there are many useful switches for filtering, sorting, etc.).

#### **2. Finding Your Current Location**

To know **where you are** in the file system, use:
```
cd
```

or
```
chdir
```

This simply prints the full path of your **current working directory**.

#### **3. Moving Around with cd / chdir**

The cd command is used to **change directories**.

**Two types of paths:**

- **Absolute Path** → Starts from the root (C:\)
    ```
    cd C:\Users\htb\Pictures
    ```
    
- **Relative Path** → Relative to your current location
    ```
    cd .\Pictures          # . means current directory
    cd ..                  # Move up one level
    cd ..\..\              # Move up two levels
    ```
    

**Useful shortcut:**
```
cd ..\..\..\           # Quickly go back to C:\ from deep folders
```

Understanding absolute vs relative paths is very important. It saves a lot of time when navigating.

#### **4. Exploring the File System with tree**

Manually using cd and dir repeatedly is slow. Use the tree command to see the directory structure visually.

**Basic tree:**
```
tree
```

**Tree with files included:**
```
tree /F
```

This is extremely useful for quickly spotting interesting files like:

- passwords.txt
- secrets.txt
- Configuration files
- Project documents

**Warning**: tree /F on the entire drive (tree /F C:\) produces **a lot** of output. Use Ctrl + C to stop it once you have what you need.

#### **Interesting Directories from an Attacker’s Perspective**

These folders are commonly targeted because they often contain useful information or allow file drops:

|Directory|Path|Why It's Interesting|
|---|---|---|
|**Windows Temp**|C:\Windows\Temp|World-writable, good for dropping files as low-priv user|
|**User Temp**|C:\Users\<username>\AppData\Local\Temp|User-specific temp files|
|**Public**|C:\Users\Public|Accessible by all users, less monitored|
|**Program Files**|C:\Program Files|Shows installed 64-bit applications|
|**Program Files (x86)**|C:\Program Files (x86)|Shows installed 32-bit applications|

These locations are great for reconnaissance and for dropping tools/payloads during an assessment.

### **Working with Directories and Files in CMD 

Now that we can navigate the system, it’s time to master creating, viewing, modifying, copying, moving, and deleting files and directories using built-in CMD commands.

#### **Directories**

A directory is basically a folder in the Windows filesystem. Everything is organized in a hierarchy starting from the root (C:\).

**Key Commands for Directories:**

1. **List contents**
    ```
    dir
    ```
    
    Shows files, folders, sizes, and dates in the current directory.
    
1. **Show current location**
    ```
    cd
    ```
    
    (or chdir) – prints the full path you’re currently in.
    
1. **Create a new directory**
    ```
    md new-folder
    ```
    
    or
    ```
    mkdir new-folder
    ```
    
    Both commands do the same thing.
    
1. **Delete a directory**
    ```
    rd foldername
    ```
    
    or
    ```
    rmdir foldername
    ```
    
    **Important**: If the directory is not empty, add the /S switch:
    ```
    rd /S foldername
    ```
    
    This deletes the folder and everything inside it (use with caution!).
    
1. **View directory tree**
    ```
    tree
    ```
    
    Shows the folder structure visually.
    
    To also see files:
    ```
    tree /F
    ```
    

#### **Files**

**Viewing Files**

- type filename.txt → Displays the content of a text file.
- more filename.txt → Shows content one screen at a time (press Space or Enter to scroll).
- more /S filename.txt → Compresses multiple blank lines for easier reading.

You can also pipe output through more:
```
ipconfig /all | more
```

**Creating and Modifying Files**

- Using echo:
    ```
    echo This is some text > demo.txt          # Create/overwrite
    echo More text here >> demo.txt            # Append
    ```
    
- Using fsutil (creates an empty file of specific size):
    ```
    fsutil file createNew test.txt 1024
    ```
    
- Renaming a file:
    ```
    ren oldname.txt newname.txt
    ```
    
    (or rename)

**Copying and Moving Files**

- copy:
    ```
    copy secrets.txt C:\Users\htb\Downloads\backup.txt
    ```
    
- move (can also rename):
    ```
    move bio.txt C:\Users\htb\Downloads\
    ```
    
- xcopy and robocopy are more powerful for directories and have many options (robocopy is the modern replacement for xcopy).

**Deleting Files**

- del or erase (they are interchangeable):
    ```
    del filename.txt
    ```
    
    Useful switches:
    
    - /F → Force delete read-only files
    - /A:R → Delete read-only files
    - /A:H → Delete hidden files
    - * → Delete all files in current directory

**Input / Output Redirection**

- > → Send output to a file (overwrite)
    ```
    ipconfig /all > details.txt
    ```
    
- >> → Append output to a file
    ```
    echo Extra line >> details.txt
    ```
    
- < → Feed a file as input to a command
- (pipe) → Send output of one command to another
    ```
    ipconfig /all | find "IPv4"
    ```
    
- & → Run command A then command B (regardless of success)
- && → Run command B only if command A succeeds
