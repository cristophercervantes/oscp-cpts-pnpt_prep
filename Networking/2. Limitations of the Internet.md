# History of the Internet
## The 1950s — the problem

Computers were massive physical machines. If you needed to use one, you had to be physically present with it. Only one person could use the available computing resource at a time.

## The 1960s — ARPANET

The US government launched a project through **DARPA** that created **ARPANET** — the earliest version of the internet. It allowed programmers to remotely access a single computing resource from different locations.

But a major problem remained: networks couldn't talk to each other.

## The 1970s — TCP/IP

Computer scientists **Vinton Cerf** and **Bob Kahn** solved the network-to-network communication problem by creating **TCP/IP** (Transmission Control Protocol / Internet Protocol).

This was the critical breakthrough. For the first time, different networks could exchange data with each other.

Adoption was gradual — first universities, governments, and businesses, then hundreds of computers, then over the next 50 years, billions.

TCP/IP is the protocol the internet still runs on today.

## The 1990s — the World Wide Web

TCP/IP solved communication, but information was text-only, scattered, and hard to navigate.

**Tim Berners-Lee** invented the **World Wide Web** — a system of protocols for displaying formatted information in webpages, accessible to anyone with an internet connection. It became the dominant way people access and share information on the internet.

## Then to now

In roughly 30 years, the internet went from basic email and simple web pages to video calls, instant news, online shopping, streaming, online education, and more.

The internet as we know it is the result of decades of work by scientists, engineers, and organizations building on each other's breakthroughs.

# IPv4, IPv6, and NAT

## IPv4 — the current standard 

**IPv4 (Internet Protocol version 4)** addresses consist of **32 bits**, written as four groups of numbers.

Example: `73.55.242.3`

Maximum possible addresses: ~4.3 billion. That sounds like a lot, but the number of internet-connected devices worldwide has already exceeded this. Some addresses are reserved for special purposes, making the usable pool even smaller.

## IPv6 

**IPv6 (Internet Protocol version 6)** addresses consist of **128 bits** — four times as many bits as IPv4.

Example: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`

The number of possible IPv6 addresses is 2¹²⁸ — an almost incomprehensibly large number. To put it in perspective: if you took every grain of sand on Earth (roughly 7.5 × 10¹⁸ grains), that still wouldn't be enough to represent the number of IPv6 addresses. You'd need the sand from multiple Earths to get close.

We will not run out of IPv6 addresses.

Adoption of IPv6 has been slow but steady and will continue to increase.

## NAT — Network Address Translation

A near-term solution to IPv4 exhaustion. NAT allows an entire organization to share a **single public IP address** while devices inside the network each have their own **private IP address**.

How it works: think of it like a company receptionist. You call one public number to reach the company. The receptionist routes your call to the right internal extension. From the outside, only one number is visible.

This means instead of a company needing hundreds of public IP addresses, they only need one.
