# The Five Layer Network Model


Networking involves many components working together — cables, protocols, routers, applications. The layered model breaks this down into distinct responsibilities so each piece can be understood and troubleshot separately.

## The five layers

### Layer 1 — Physical

The actual physical hardware: cables, connectors, and the signals sent over them. This is the copper wire, fiber optic cable, and the specs for how electrical or light signals travel through them.

### Layer 2 — Data Link (also called Network Interface or Network Access)

Defines how devices interpret the physical signals so they can communicate. The most common protocol here is **Ethernet** (with wireless becoming increasingly common). The data link layer is responsible for getting data between nodes on the **same network**.

### Layer 3 — Network (also called Internet layer)

Allows **different networks** to communicate through routers. A collection of networks connected via routers is called an **internetwork** — the internet is the most well-known example. The primary protocol here is **IP (Internet Protocol)**. The network layer gets data from one node to another across multiple networks.

### Layer 4 — Transport

Determines which **application** on a node should receive the data. The network layer gets data to the right machine — the transport layer gets it to the right program running on that machine.

Two main protocols:

- **TCP (Transmission Control Protocol)** — ensures reliable delivery, confirms data arrives correctly
- **UDP (User Datagram Protocol)** — faster but no delivery guarantee

### Layer 5 — Application

Application-specific protocols that you interact with directly — web browsing (HTTP/HTTPS), email (SMTP, IMAP), file transfer, and more. These are the protocols most familiar to everyday users.

## The delivery analogy

|Layer|Analogy|
|---|---|
|Physical|The delivery truck and the roads|
|Data Link|How the truck moves from one intersection to the next|
|Network|Which roads to take to get from address A to address B|
|Transport|The driver knocking on your door to hand off the package|
|Application|The contents of the package itself|

## TCP vs IP — not the same thing

TCP/IP is a common phrase but refers to two different protocols at two different layers:

- **IP (Layer 3)** — gets data to the right machine
- **TCP (Layer 4)** — gets data to the right application on that machine, and ensures it arrives reliably

Understanding this distinction is essential for troubleshooting networking issues.
